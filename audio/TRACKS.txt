Source of truth
---------------
manifest.json     — merged at runtime into the library
radio-feed.json   — continuous radio / channel queue

How to add music
----------------
1. Drop an .mp3 into /audio/
2. Add one object to manifest.json "tracks"
3. Optionally append to radio-feed.json "tracks"
4. Commit + push (Pages updates in about a minute)

Rules
-----
- Do not commit the same binary under two names
- Covers are local SVG via js/covers.js (no external image CDN)
- Prefer 128–192 kbps MP3 to keep the repo light
