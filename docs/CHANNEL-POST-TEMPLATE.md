# قالب حرفه‌ای پست کانال — SONORA / MrA_Music

ربات فقط وقتی کار می‌کند که:
1. `@MrA_Music_bot` **ادمین کانال** باشد (دسترسی Post messages)
2. کپشن پست دقیقاً با یکی از قالب‌های زیر باشد
3. فایل **صوتی / سند MP3** به همان پیام پیوست باشد

---

## قالب اصلی (کپی کن و پر کن)

```
🎵 SONORA

Title: نام آهنگ
Artist: نام خواننده / گروه
Album: نام آلبوم
Year: 2026
Genre: Electronic
Duration: 3:45

#sonora #new
```

### مثال واقعی

```
🎵 SONORA

Title: Glass Horizon
Artist: Aurora Vale
Album: Midnight Signals
Year: 2026
Genre: Alternative / Electronic
Duration: 4:12

#sonora #aurora
```

---

## قالب کوتاه (حداقلی)

اگر عجله داری، همین کافی است:

```
Title: نام آهنگ
Artist: نام خواننده
```

Album / Year / Genre اختیاری‌اند؛ ربات از ID3 داخل فایل هم می‌خواند.

---

## قوانین کپشن

| فیلد | اجباری؟ | توضیح |
|------|---------|--------|
| Title | بله | نام ترک |
| Artist | بله | خواننده |
| Album | خیر | پیش‌فرض: Singles |
| Year | خیر | عدد چهاررقمی |
| Genre | خیر | مثلاً Electronic |
| Duration | خیر | `m:ss` |

- خطوط خالی و ایموجی اول پیام اشکالی ندارد
- حروف Title/Artist بزرگ‌وکوچک مهم نیست
- می‌توانی از `عنوان:` و `خواننده:` به‌جای انگلیسی هم استفاده کنی (ربات هر دو را می‌فهمد)

### معادل فارسی

```
عنوان: نام آهنگ
خواننده: نام خواننده
آلبوم: نام آلبوم
ژانر: الکترونیک
سال: 2026
مدت: 3:45
```

---

## کاور

- اگر داخل MP3 کاور ID3 باشد → همان روی سایت می‌آید
- اگر نباشد → کاور SVG محلی SONORA ساخته می‌شود
- می‌توانی عکس را جدا در کانال بفرستی؛ همگام‌سازی فعلی روی **همان پیام صوت** تمرکز دارد

---

## بعد از پست

1. GitHub Action هر چند دقیقه `getUpdates` را می‌خواند
2. فایل را در `audio/` کامیت می‌کند
3. `manifest.json` و `radio-feed.json` را به‌روز می‌کند
4. حدود ۱ دقیقه بعد روی GitHub Pages پخش می‌شود

---

## امنیت

توکن ربات را **هرگز** در چت یا ریپو نگذار. فقط در:

`GitHub → Settings → Secrets and variables → Actions`

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHANNEL_ID` = `@MrA_Music`
